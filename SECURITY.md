# Sicherheitslücken melden

Wenn Sie eine Schwachstelle in Besucherlogin finden, melden Sie sie bitte
**vertraulich per E-Mail** an:

**kontakt@integrisec.de**

Bitte legen Sie **kein öffentliches Issue** an, solange die Lücke nicht behoben
ist – auch nicht als Hinweis ohne Details. Installationen dieser Software
verarbeiten Besucherdaten; eine öffentliche Meldung setzt Betreiber einem
Risiko aus, bevor sie reagieren können.

## Was in die Meldung gehört

- betroffene Datei oder Funktion, möglichst mit Version oder Commit
- wie sich das Problem reproduzieren lässt
- welche Auswirkung Sie sehen

## Was Sie erwarten können

- **Eingangsbestätigung innerhalb weniger Werktage**
- eine Einschätzung, ob und wie wir das Problem beheben
- auf Wunsch eine Nennung als Finder, sobald der Fix veröffentlicht ist

Vielen Dank – eine vertrauliche Meldung hilft allen Betreibern mehr als ein
schneller öffentlicher Hinweis.
